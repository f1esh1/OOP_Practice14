# Дизайн-документ: Текстова покрокова гра

## 1. Загальний опис проєкту
Проєкт є консольною покроковою грою, побудованою на принципах об'єктно-орієнтованого програмування (OOP) з чітким виділенням бізнес-логіки (шар Core). Гравець взаємодіє з ігровим світом через командний рядок, виконує покрокові дії, веде історію ходів та має можливість зберігати чи завантажувати стан гри.

## 2. Основні сутності (Класи)
- **`Character` (Персонаж):** Зберігає характеристики бодючого юніта (Ім'я, Здоров'я (`HP`), Сила атаки (`Attack`), Захист (`Defense`)).
- **`GameEngine` / `GameManager` (Ядро гри):** Керує ігровим циклом, чергою ходів та станом поєдинку/пригоди.
- **`GameHistory` (Історія кроків):** Зберігає лог усіх подій, що відбулися під час сесії.
- **`SaveManager` (Збереження стану):** Відповідає за серіалізацію та десеріалізацію ігрового процесу у файл (формат JSON).

## 3. Математика та механіка взаємодії
- **Формула розрахунку шкоди (Damage):**
  $$\text{Damage} = \max(1, \text{Attacker.Attack} - \text{Defender.Defense})$$
  *(Якщо захист перевищує атаку, мінімальна шкода все одно дорівнює 1).*
- **Логіка ходу:**
  1. Гравець обирає дію на поточному кроці (Атака, Лікування, Збереження, Вихід).
  2. Система обробляє дію гравця, вираховує нові показники здоров'я.
  3. Противник робить свій хід (автоматична атака).
  4. Подія фіксується в історії кроків (`History`).

## 4. Збереження та завантаження
- Стан гри зберігається у локальний файл за допомогою серіалізації.
- Передбачено метод для завантаження як збереженої партії, так і нових персонажів із зовнішніх джерел або файлів конфігурації.
